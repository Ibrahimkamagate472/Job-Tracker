# Project Management System
Developed a full-stack job application tracking system with secure user authentication and account management. 
Implemented CRUD functionality, allowing users to create, view, update, and delete job applications while 
storing key details such as company name, position, application date, status, job posting link, and optional 
portal credentials. Built status tracking features to monitor application progress through stages including 
Applied, Interviewing, Offer, and Rejected.
